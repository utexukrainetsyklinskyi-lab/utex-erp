# Django archive

Це збережена попередня реалізація UTEX ERP на Django. Вона лишається для довідки щодо моделей, історії міграцій, адмінки та старих шаблонів.

Поточний застосунок запускається з кореня через npm run dev або npm start. Він використовує EJS-шаблони з ../../views, статичні файли з ../../public та SQLite. Архів не є частиною Node-запуску; щоб відновити Django-запуск, потрібно окремо адаптувати шляхи й залежності.
