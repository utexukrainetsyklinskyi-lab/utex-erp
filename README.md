# UTEX ERP

Вебзастосунок для обліку виробництва. Поточний сервер працює на Node.js, Express, EJS і SQLite. Django-код збережено окремо як історичне джерело моделей, міграцій та старої адмінки.

## Запуск

Потрібен Node.js 22.13 або новіший. У PowerShell з кореня проєкту виконайте:

    npm install
    npm run dev

Відкрийте http://127.0.0.1:8000. Для звичайного запуску без автоматичного перезапуску використовуйте npm start.

## Структура

- server.js — запуск Express, сесії, middleware та статичні файли.
- src/ — маршрути, автентифікація й робота з SQLite.
- views/ — EJS-шаблони сторінок і спільні частини інтерфейсу.
- public/ — CSS, JavaScript, логотип і бібліотека графіка Ганта.
- scripts/database/ — допоміжні операції з базою даних.
- legacy/django/ — архів попередньої Django-версії; Node-застосунок її не запускає.
- .data/ — локальна SQLite-база; не додається до Git.
- node_modules/ — встановлені npm-залежності; не додається до Git.

## Дані та налаштування

За замовчуванням SQLite зберігається в .data/utex.sqlite3. Шлях можна змінити через DB_PATH. Локальна база перенесена з попередньої версії. Для копії бази використовуйте:

    python scripts/database/backup_sqlite.py .data/utex.sqlite3 .data/backup.sqlite3

Скрипт створює нову копію та перевіряє її цілісність; файл призначення має ще не існувати.

Скопіюйте .env.example у .env, щоб задати параметри. Для production встановіть NODE_ENV=production і випадковий SESSION_SECRET довжиною щонайменше 32 символи. COOKIE_SECURE=1 потрібен лише за доступу через HTTPS.

## Функції

- Огляд виробництва, замовлення та автоматичне створення виробничих етапів зі специфікації.
- Виробничий план, журнал випуску, простоїв і відхилень.
- Довідники та графік Ганта.
- Адміністрування користувачів і довідкових даних; доступ до адмінрозділу має суперкористувач.
- Вхід сумісний з наявними паролями Django PBKDF2.
